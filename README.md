# 🏥 MedAssist — Hospital Volunteer Hub & Non-Clinical Patient Support

> **Цифровая платформа управления волонтерской службой стационара и координации немедицинской помощи пациентам.**
> Разработано для оптимизации работы больницы, разгрузки врачей и медсестер, а также сбора объективных операционных данных для исследовательского портфолио.

---

## 📌 О проекте (Problem & Solution)

В стационарах медицинский персонал тратит до **20–30% рабочего времени** на немедицинские задачи: сопровождение пациентов на обследования (МРТ, УЗИ, ЭКГ), транспортировку маломобильных больных на креслах-колясках, доставку результатов анализов и документов.

**MedAssist** связывает медицинский персонал, координаторов и волонтеров в единую экосистему:
1. **🩺 Медперсонал:** создает заявку на немедицинскую помощь в 2 клика.
2. **🎛️ Диспетчер / Координатор:** назначает свободных волонтеров с учетом их текущей смены.
3. **🤝 Волонтеры:** принимают вызовы, фиксируют время выполнения и ведут учет подтвержденных часов.
4. **📊 Аналитика:** система автоматически рассчитывает сэкономленные часы, строит графики нагрузки и позволяет выгружать отчеты в Excel (CSV).

---

## 🔒 Политика конфиденциальности (Zero-PII Compliance)

Приложение спроектировано по принципу **«Privacy by Design»**:
- ❌ **Категорически исключены:** ФИО пациентов, диагнозы, истории болезни, номера телефонов и карты.
- ✅ **Используются только анонимные токены:** Номер заявки (`№001`), отделение, категория помощи, срочность и время.

## 👥 Организационная структура (9 ролей команды)

| № | Роль | Кол-во | Зона ответственности |
|---|---|---|---|
| 1 | **Project Lead** | 1 чел. | Руководство проектом, стратегия, коммуникация с главврачом, защита на конкурсах/вузах |
| 2 | **Deputy / Co-lead** | 1 чел. | Замещение лидера, контроль дедлайнов, решение оперативных вопросов на сменах |
| 3 | **Volunteer Coordinator** | 1–2 чел. | Расписание смен, учет посещаемости, оперативная замена волонтеров |
| 4 | **Training & Safety Officer** | 1 чел. | Инструктаж по технике безопасности, гигиене, Zero-PII и регламентам стационара |
| 5 | **Patient Assistants** | 4 чел. | Сопровождение маломобильных пациентов на обследования, базовая поддержка |
| 6 | **Doctor Assistants** | 2 чел. | Помощь врачам и старшим медсестрам с немедицинской логистикой и документами |
| 7 | **Logistics & Supplies** | 1 чел. | Контроль бейджей, расходников, инвентаря и порядок в волонтерском штабе |
| 8 | **IT & Data Team** | 1 чел. | Поддержка приложения MedAssist, сбор данных, аналитика и построение дашбордов |
| 9 | **PR / Outreach** | 1 чел. | Освещение проекта в школе/соцсетях, анкетирование и привлечение новых волонтеров |

## 🛠️ Технологический стек (Tech Stack)

- **Frontend:** React 18, Vite 6
- **Styling:** Tailwind CSS (Clean Hospital Clinical UI)
- **Icons:** Lucide React
- **Data Visualization:** Recharts
- **Storage:** LocalStorage (автономное сохранение данных без сторонних серверов)
- **Export:** CSV / Excel, печать отчетов и сертификатов в PDF

## 🚀 Установка и запуск (Quick Start)

### 1. Клонирование репозитория
```bash
git clone https://github.com/ErkhanShamahammadov/Medassist.git
cd Medassist
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```

Приложение откроется по адресу: `http://localhost:3000`

### 4. Сборка для продакшена
```bash
npm run build
```
